# Nmap Notes

A small reference repository containing package-installation notes for Nmap.

## Contents

- `textfile(1).txt`: package manager notes for several Linux distributions.

## Responsible use

Network discovery and scanning should only be performed on systems and networks you own or are explicitly authorized to assess. Follow your institution's rules and the applicable laws.

This repository is a notes collection, not an official Nmap project. Refer to the official Nmap documentation for authoritative product information.
